# ENI_BrandValue_web

Static brand value report site for the ENI group.

## Contents

- `index.html`: main report entry point
- `serie-a.html`: alternate report view
- `app.js`, `data.js`, `report.css`: application logic, data, and styling
- `assets/`: logos and media assets
- `ds-kit/`: shared design system assets and components

## Run locally

Open `index.html` in a browser.
